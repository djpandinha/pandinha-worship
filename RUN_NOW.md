# 🎵 PANDINHA WORSHIP - GUIA RÁPIDO

## ⚡ COPIE E COLE ISTO NO TERMINAL:

```bash
git clone https://github.com/djpandinha/pandinha-worship.git
cd pandinha-worship
npm run setup
npm run docker
```

## 🌐 DEPOIS ABRA NO NAVEGADOR:

- **Frontend:** http://localhost:3000
- **Backend:** http://localhost:5000
- **API Health:** http://localhost:5000/api/health

## ✋ SE DOCKER NÃO FUNCIONAR:

```bash
# Terminal 1
npm run frontend

# Terminal 2 (novo terminal)
npm run backend
```

## 🛑 PARAR TUDO:

```bash
npm run docker:down
```

**Pronto!** Seu projeto vai rodar 100% funcional na sua rede! 🚀
