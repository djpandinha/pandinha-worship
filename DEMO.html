Pronto para começar?

Seu projeto PANDINHA WORSHIP está 100% pronto para rodar na sua rede!

Opção 1: Com Docker 🐳

git clone https://github.com/djpandinha/pandinha-worship.git
cd pandinha-worship
npm run setup
npm run docker

✅ Tudo em 1 comando! Frontend + Backend rodando na rede

Opção 2: Manual 🚀

git clone https://github.com/djpandinha/pandinha-worship.git
cd pandinha-worship
npm run setup
npm run frontend  # Terminal 1
npm run backend   # Terminal 2

🌐 http://localhost:3000 + http://localhost:5000
