🚀 Como Usar Seu Projeto

Opção 1: Docker (Recomendado) 🐳

A forma mais fácil! Tudo roda em 1 comando.

git clone https://github.com/djpandinha/pandinha-worship.git
cd pandinha-worship
npm run setup
npm run docker

✅ Pronto! Acesse: http://localhost:3000

Opção 2: Manual (2 Terminais) 🚀

Se preferir rodar sem Docker.

git clone https://github.com/djpandinha/pandinha-worship.git
cd pandinha-worship
npm run setup

Depois abra 2 terminais:

Terminal 1: npm run frontend
Terminal 2: npm run backend

✅ Acesse: http://localhost:3000 + http://localhost:5000
