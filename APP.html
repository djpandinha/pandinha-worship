🚀 Como Usar

✨ Opção 1: Com Docker (Recomendado) 🐳

A forma mais fácil! Tudo roda em 1 comando e você não precisa instalar nada além do Docker.

git clone https://github.com/djpandinha/pandinha-worship.git
cd pandinha-worship
npm run setup
npm run docker

✅ Pronto! Acesse em: http://localhost:3000

🚀 Opção 2: Manual (Sem Docker) 🎯

Se preferir rodar manualmente em 2 terminais.

git clone https://github.com/djpandinha/pandinha-worship.git
cd pandinha-worship
npm run setup

Depois abra 2 terminais:

Terminal 1: npm run frontend
Terminal 2: npm run backend

✅ Acesse: http://localhost:3000 + http://localhost:5000
