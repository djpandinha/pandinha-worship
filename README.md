## 🎨 Design System

### Paleta de Cores
- **Rosa Neon:** `#FF1493`
- **Magenta Neon:** `#FF00FF`
- **Preto:** `#0A0E27`
- **Branco:** `#FFFFFF`
- **Cinza Escuro:** `#1A1F3A`

### Tipografia
- **Heading:** Poppins Bold (Moderna e vibrante)
- **Body:** Inter Regular (Limpa e legível)
- **Accent:** Space Mono (Para elementos especiais)
